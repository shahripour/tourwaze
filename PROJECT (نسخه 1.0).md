# Coding Rules

✔ TypeScript Strict

✔ هیچ any استفاده نشود

✔ Server Component تا جایی که امکان دارد

✔ Client Component فقط در صورت نیاز

✔ تمام Query ها داخل services

✔ هیچ Query داخل Component نوشته نشود

✔ تمام State های سراسری داخل Context

✔ تمام Validation با Zod

✔ تمام Form ها با React Hook Form
